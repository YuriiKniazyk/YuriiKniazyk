## 👨‍💻 About me

Software engineer with **5+ years** of hands-on experience in **Node.js** and **real-time systems**.
I build production-grade backends, integrate **AI/LLM** services, and make things fast and reliable.

- 🔭 Currently at **Ravatar**, building the backend for **real-time AI avatars**: LLMs, voice, and Unreal Engine Pixel Streaming
- 🧠 Integrating **OpenAI, Gemini and Claude**, plus **TTS/STT** pipelines with ElevenLabs and Whisper

- 🇺🇦 Based in Ukraine

## 🤖 AI-native engineering

I work with **[Claude Code](https://claude.com/claude-code)** as an everyday engineering partner, not just autocomplete.

- ⚡ **Agentic workflow.** Claude Code runs both in my IDE (VS Code) and in cloud sessions. I delegate well-scoped tasks to it, such as refactors, wiring new parameters through a service, and boilerplate. I keep the architecture and the final review.
- 🔍 **AI-assisted code review.** Every change gets a second pass before it ships, looking for bugs, edge cases and simplifications.
- 🧪 **Tests and verification first.** The AI proposes, but CI and tests decide. Nothing merges on vibes.
- 🛠️ **Beyond code.** I use it for automating GitHub workflows, docs, and even this profile, which was built together with Claude.
- 🧰 Also in the toolbox: **Cursor**, **ChatGPT** and **Gemini**.

> I also build AI products for a living, so I know LLMs from both sides: as a developer tool and as a production dependency.
